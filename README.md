<h1>Belajar Pengembangan Web Intermediate submission 2</h1>
<p>Repository ini dibuat untuk menyelesaikan tugas submission 2 di kelas Belajar Pengembangan Web Intermediate dicoding</p>

<h2>Installation</h2>
<h3>a. Clone atau download repository ini ke computer kalian</h3>
<h3>b. Jalankan perintah</h3>
<p>Di editor kalian, buka terminal (CTRL + ` ) lalu masukkan perintah</p>
<ul>
  <li>npm install</li>
  <li>npm run dev</li>
</ul>

<h3>c. Masuk ke alamat yang diberikan dan selesai !</h3>
<h3>d. Jika ingin hasil build maka tinggal masukkan perintah = npm build</h3>
